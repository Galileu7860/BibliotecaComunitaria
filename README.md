# BibliotecaComunitaria
O **BiblioTech** é uma solução de software multiplataforma voltada para a gestão completa de bibliotecas comunitárias. O sistema permite o gerenciamento de acervos, empréstimos, devoluções, cadastro de membros e divulgação de eventos culturais, promovendo o acesso democrático à cultura e ao conhecimento em Fortaleza e região.
